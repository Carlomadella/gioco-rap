# I prompt

Quello che si incolla in una chat con l'AI per farsi fare **le immagini e i testi
del gioco**. Non sono documentazione: sono materiale di lavoro, e ognuno è
autosufficiente — si copia una sezione intera e la si incolla, senza doverla
mettere insieme ad altre.

| file | cosa ci si genera |
| --- | --- |
| [`prompt-ambientazioni.md`](prompt-ambientazioni.md) | i fondali dei luoghi: la mappa, lo studio, La Sala, la strada… |
| [`prompt-app-telefono.md`](prompt-app-telefono.md) | le schermate delle app del telefono |

Le foto che escono da qui vanno in `frontend/media/photo/`, quelle scartate o
ancora da collegare in `frontend/concept/` — che il build non guarda, così non
finiscono nel pacchetto per gli store senza che nessuno le chieda.
