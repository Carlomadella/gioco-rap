# FAME GENRE RESEARCH — INDEX

Questo documento è l'indice della ricerca per genere.

Ogni genere deve essere studiato in queste aree:

1. RHYTHM DNA
   - kick
   - snare/clap
   - closed hats
   - open hats
   - crash
   - percussion
   - swing / triplet / grid

2. BASS DNA
   - tipo di basso
   - note density
   - glide
   - distortion
   - relazione col kick

3. HARMONY DNA
   - scale
   - chord types
   - progression tendencies
   - voicing

4. MELODY DNA
   - strumenti ricorrenti
   - registri
   - motif
   - repetition
   - ornamentation

5. SOUND DNA
   - synth
   - sampler
   - texture
   - processing

6. ARRANGEMENT DNA
   - intro
   - verse
   - hook
   - break
   - transitions
   - typical phrase lengths

7. MIX DNA
   - low end
   - width
   - brightness
   - FX
   - drum prominence

8. IDENTITY MODEL
   - CORE ANCHORS
   - STRONG CLICHES
   - STYLE CLICHES
   - VARIATION SPACE
   - FORBIDDEN AUTOMATISMS

## Stato attuale
Trap: ricerca iniziale già avviata.
Altri generi: da formalizzare sistematicamente.
