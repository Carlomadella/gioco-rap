# FAME — AGENT BOOTSTRAP

ATTENZIONE: questo file è parte della memoria ufficiale del progetto.

Prima di proporre o applicare QUALSIASI modifica a FAME:

1. Leggere `START_HERE.md`.
2. Leggere `docs/FAME_MASTER_SPEC.md`.
3. Leggere `docs/CURRENT_STATE.md`.
4. Leggere `docs/DECISIONS.md`.
5. Leggere `docs/REJECTED_APPROACHES.md`.
6. Leggere la spec del genere coinvolto in `specs/genres/`.
7. Leggere `docs/ROADMAP_FAME.md`.
8. Leggere `tests/REGRESSION_TESTS.md`.

REGOLE:
- Non usare la memoria della chat come fonte primaria se questi file sono disponibili.
- Non reintrodurre un approccio presente in REJECTED_APPROACHES senza una decisione esplicita.
- Non modificare un sottosistema marcato APPROVED/FROZEN insieme a un altro sottosistema senza necessità.
- Se una nuova decisione cambia la direzione, aggiornare la memoria nello stesso commit del codice.
- Ogni build deve dichiarare FIXED / CHANGED / UNCHANGED / KNOWN ISSUES.
- Se il test uditivo contraddice l'audit numerico, il problema resta aperto.
