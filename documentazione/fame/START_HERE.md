# FAME PROJECT MEMORY V1 — START HERE

Questa cartella è la memoria ufficiale del progetto FAME.

## Regola principale
La chat serve per decidere.
Questi file servono per ricordare.

Prima di modificare FAME bisogna leggere, nell'ordine:

0. `AGENT_BOOTSTRAP.md`

1. `docs/FAME_MASTER_SPEC.md`
2. `docs/CURRENT_STATE.md`
3. `docs/DECISIONS.md`
4. `docs/REJECTED_APPROACHES.md`
5. la spec del genere interessato in `specs/genres/`
6. `tests/REGRESSION_TESTS.md`

Una modifica NON è considerata completa finché non sono aggiornati:
- codice;
- specifiche;
- stato corrente;
- decision log se necessario;
- regression test se necessario;
- changelog.

## Stato iniziale di questo pacchetto
Riferimento: FAME V0.8 Rhythm & Arrangement Pass.

Questa memoria NON incorpora codice di Strudel o di Switch Angel.
Le idee studiate vengono reimplementate clean-room.
